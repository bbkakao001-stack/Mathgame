Section 8.1 • ตารางสองทาง

Two-way Tables

ตารางสองทาง — จัดข้อมูลสองตัวแปรโดยใช้แถวและคอลัมน์

What is a two-way table?

A two-way table organises data for two different variables using columns and rows. One variable is shown in the rows; the other in the columns.

ตารางสองทางใช้สำหรับจัดข้อมูลที่มีสองตัวแปร โดยแสดงตัวแปรหนึ่งในแถว และอีกตัวแปรหนึ่งในคอลัมน์

Tip: When you complete a two-way table, check carefully that all the rows and columns add up to the correct totals.

Dual & Compound Bar Charts

แผนภูมิแท่งคู่ และแผนภูมิแท่งซ้อน

Dual Bar Chart

Two groups shown side by side.

Yellow = boys • Teal = girls

Compound Bar Chart

Bars stacked on top of each other.

Stacked: boys (bottom) + girls (top)
Discussion • อภิปราย

Advantages & Disadvantages

ข้อดีและข้อเสียของแผนภูมิแท่งคู่และแท่งซ้อน

Dual Bar Chart

Advantage: Easy to compare individual group values side by side.

Disadvantage: Harder to see the total for the category.

Compound Bar Chart

Advantage: Easy to see the total for each category.

Disadvantage: Harder to compare individual groups.

Section 8.3 • แผนภูมิความถี่

Frequency Diagrams

แผนภูมิความถี่สำหรับข้อมูลต่อเนื่อง

Key Ideas

  • Used to display grouped continuous data (e.g. heights, masses, times).
  • Bars should be drawn without gaps because the data is continuous.
  • Intervals should have equal width.
  • The y-axis shows frequency; the x-axis shows the intervals.
Tip: "18 – 20 kg" means masses from 18 kg up to (but not including) 20 kg.

Key Terms • คำศัพท์

Two-way Tables

คำศัพท์ที่เกี่ยวข้องกับตารางสองทาง

  • Two-way table: A table organising data for two different variables using rows and columns.
  • Variable: Something that can change or be measured.
  • Total: The sum of all values in a row or column.
Key Terms • คำศัพท์

Dual & Compound Bar Charts

คำศัพท์เกี่ยวกับแผนภูมิแท่งคู่และซ้อน

  • Dual bar chart: A bar chart for showing data from two groups side by side.
  • Compound bar chart: A bar chart showing data for two or more groups with the bars stacked on top of each other.
  • Key (Legend): A guide showing what each colour or symbol represents.
Key Terms • คำศัพท์

Frequency Diagrams

คำศัพท์เกี่ยวกับแผนภูมิความถี่

  • Frequency: How often something happens.
  • Continuous data: Data that can take any value in a range (e.g. height, time).
  • Interval: A range of values, e.g. 10–20. Equal width intervals should touch.
Key Terms • คำศัพท์

Continuous vs Discrete

ข้อมูลต่อเนื่อง vs ข้อมูลไม่ต่อเนื่อง

Continuous Data

Data that can take any value within a range.

Examples: Height, mass, time, temperature.

Bars in frequency diagram must touch.

Discrete Data

Data that can only take specific values.

Examples: Number of students, shoe size, number of items.

Bars in bar chart usually have gaps.

Continuous data → bars touch. Discrete data → bars have gaps.

Summary • สรุป

Estimation from Samples

การประมาณการจากตัวอย่าง

How to Estimate

1. Find the fraction in the sample.

2. Assume the population has the same fraction.

3. Multiply the fraction by the total population.

Example: 5/60 trees over 40m. Park has 264 trees. Estimate = 5/60 × 264 = 22 trees.
